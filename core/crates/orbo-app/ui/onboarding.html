Alles läuft lokal auf deinem Mac

So funktioniert Orbo

Datei ziehen, ⌥ halten oder schütteln und auf einem Feld ablegen.

Ordner freigeben

macOS fragt einmalig pro geschütztem Ordner, ob Orbo auf Dateien zugreifen darf. Orbo lädt keine Daten hoch und sendet nichts ins Netzwerk.

Schreibtisch~/DesktopNicht freigegeben
Dokumente~/DocumentsNicht freigegeben
Downloads~/DownloadsNicht freigegeben

Die Freigabe kannst du jederzeit nachholen. Ohne Freigabe fragt macOS erst beim ersten Zugriff.
